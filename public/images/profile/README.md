# Profile photographs

Put your professional portrait here, e.g. `profile/mirembe.png`.

Then open `src/data/content.js` and set:

```js
photo: "/images/profile/mirembe.png",
```

The hero section uses it immediately (the monogram placeholder disappears).

- Portrait orientation (~4:5) works best in the hero frame.
- Keep it under ~500 KB for fast loading.
